# Expectation-Predict vignette for the Inverse Burr distribution, with Median parametrization. The mean only exists for gamma \> 1.

Expectation-Predict vignette for the Inverse Burr distribution, with
Median parametrization. The mean only exists for gamma \> 1.

## Usage

``` r
posterior_epred_inverse_burr(prep)
```

## Arguments

- prep:

  brms data

## Value

Expected value of the Inverse Burr distribution given data in prep
