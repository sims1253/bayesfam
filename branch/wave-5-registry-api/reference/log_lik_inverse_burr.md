# Log-Likelihood vignette for the Inverse Burr distribution, with Median parametrization.

Log-Likelihood vignette for the Inverse Burr distribution, with Median
parametrization.

## Usage

``` r
log_lik_inverse_burr(i, prep)
```

## Arguments

- i:

  brms indices

- prep:

  brms data

## Value

Log-Likelihood of Inverse Burr given data in prep
