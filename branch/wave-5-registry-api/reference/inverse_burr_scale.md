# Scale of the Inverse Burr distribution in Median parametrization.

Scale of the Inverse Burr distribution in Median parametrization.

## Usage

``` r
inverse_burr_scale(mu, tau, gamma)
```

## Arguments

- mu:

  Median parameter, mu \> 0

- tau:

  Shape1 parameter, tau \> 0 (actuar: shape1)

- gamma:

  Shape2 parameter, gamma \> 0 (actuar: shape2)

## Value

The actuar scale parameter sigma(mu, tau, gamma)
