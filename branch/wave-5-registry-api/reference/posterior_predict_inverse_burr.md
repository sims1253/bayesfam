# Posterior-Prediction vignette for the Inverse Burr distribution, with Median parametrization.

Posterior-Prediction vignette for the Inverse Burr distribution, with
Median parametrization.

## Usage

``` r
posterior_predict_inverse_burr(i, prep, ...)
```

## Arguments

- i:

  brms indices

- prep:

  brms data

- ...:

  Catchall argument

## Value

Posterior prediction of Inverse Burr, given data in prep
