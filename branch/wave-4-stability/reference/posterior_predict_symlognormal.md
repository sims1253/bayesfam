# Posterior-predict for the symlognormal distribution, with Median parametrization.

Posterior-predict for the symlognormal distribution, with Median
parametrization.

## Usage

``` r
posterior_predict_symlognormal(i, prep, ...)
```

## Arguments

- i:

  Indices

- prep:

  brms data

- ...:

  catchall

## Value

The posterior prediction of the symlognormal distribution, given some
brms data.
