# Posterior-predict vignette for the Logitnormal distribution, with Median parametrization.

Posterior-predict vignette for the Logitnormal distribution, with Median
parametrization.

## Usage

``` r
posterior_predict_logitnormal(i, prep, ...)
```

## Arguments

- i:

  Indices

- prep:

  brms data

- ...:

  Catchall argument

## Value

The posterior prediction of the Logitnormal distribution, given some
brms data.
