# Posterior-predict vignette for the Cauchitnormal Distribution

Posterior-predict vignette for the Cauchitnormal Distribution

## Usage

``` r
posterior_predict_cauchitnormal(i, prep, ...)
```

## Arguments

- i:

  Indices

- prep:

  brms data

- ...:

  Catchall argument

## Value

The posterior prediction of the Cauchitnormal Distribution, given some
brms data.
