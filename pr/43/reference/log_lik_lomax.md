# Log-Likelihood vignette for the Lomax distribution, with Mean parametrization.

Log-Likelihood vignette for the Lomax distribution, with Mean
parametrization.

## Usage

``` r
log_lik_lomax(i, prep)
```

## Arguments

- i:

  brms indices

- prep:

  brms data

## Value

Log-Likelihood of Lomax given data in prep
