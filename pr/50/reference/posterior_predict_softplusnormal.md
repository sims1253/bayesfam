# Posterior-predict vignette for the Softplus distribution, with Median parametrization.

Posterior-predict vignette for the Softplus distribution, with Median
parametrization.

## Usage

``` r
posterior_predict_softplusnormal(i, prep, ...)
```

## Arguments

- i:

  Indices

- prep:

  brms data

- ...:

  Catchall argument

## Value

The posterior prediction of the Softplus distribution, given some brms
data.
