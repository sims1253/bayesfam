# RNG for a mixture of inverse gaussian distributions

Based on code from simplexreg Peng Zhang, Zhenguo Qiu, Chengchun Shi
(2016). simplexreg: An R Package for Regression Analysis of Proportional
Data Using the Simplex Distribution. Journal of Statistical Software,
71(11), 1-21. doi:10.18637/jss.v071.i11

## Usage

``` r
rMIG(epsilon, Tau, mu)
```

## Arguments

- epsilon:

  epsilon parameters of the mixture parts

- Tau:

  tau parameters of the mixture parts

- mu:

  mu parameters of the mixture parts

## Value

a single sample for the specified mixture
